# PALS Documentation Repository (`docs/`)

> **Purpose:** Central architectural documentation, visual diagrams, and research specifications.

---

## 1. Directory Structure

```text
docs/
├── architecture/       # Deep-dive architectural diagrams, threat models, and sequence charts
├── knowledge/          # Raw and processed knowledge assets
│   └── paypal/         # Official PayPal consumer and developer documentation for GLY RAG
└── research/           # Competitive analysis, benchmark reports, and prototype evaluations
    └── OPENMAUSBOT_AND_OPENDOT_ANALYSIS.md  # Architectural analysis of OpenMausBot & OpenDot patterns
```

---

## 2. Maintenance Policy

- Documentation is a first-class citizen in PALS.
- All diagrams should be stored as editable Mermaid (`.mmd` or fenced markdown blocks).
- Knowledge corpus files in `docs/knowledge/paypal/` must retain source URLs and retrieval dates for auditability.
